# CueFlow 1.0.1

CueFlow 1.0.1 — 本地优先的 Android 提词器。

## 下载

- `CueFlow-1.0.1.apk`（最新正式签名版，Android 7.0+）
- 旧版本保留在 [v1.0.0](https://github.com/ToolsMaker292/CueFlow/releases/tag/v1.0.0)

## 本次更新

- **未开始录制也能隐藏预览**：相机小窗不会再挡住提词文字。
- **隐藏后可直接开始录制**：右上角保留“显示预览”和红色“开始录制”两个紧凑按钮，不需要先展开预览。
- **录制中隐藏保持不变**：录制时仍可隐藏为顶部小红点，录制持续进行；点击小红点恢复预览并可停止。
- **录制结束自动回到空闲控制**：停止或失败后，隐藏状态会显示开始录制按钮，不会卡在只有红点。
- 保留旧版 APK，可回退到 1.0.0。
