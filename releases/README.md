# CueFlow 1.1.1

最新正式签名 APK，包含 PP-OCRv6 small 离线 OCR，并修复部分图片方向/读取问题。

```bash
adb install -r CueFlow-1.1.1.apk
```

也可以把 APK 传到手机后点击安装。系统要求 Android 7.0（API 24）及以上。

旧版本 `CueFlow-1.1.0.apk`、`CueFlow-1.0.2.apk`、`CueFlow-1.0.1.apk`、`CueFlow-1.0.0.apk` 仍保留，可回退。SHA-256 见 `SHA256SUMS.txt`。

> 这个 APK 使用项目测试签名证书，适合直接测试和试用。发布到应用商店前，请用自己的密钥重新签名 Release 包，步骤见根目录 README。
